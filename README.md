# 🖼️ Image Gallery

A simple and responsive **Image Gallery Mini Project** built using HTML, CSS, and JavaScript. ✨

## 🚀 Features

* 🖼️ Beautiful image gallery
* 🎨 Clean and simple UI
* 📱 Responsive design
* ⚡ Fast and lightweight

## 🛠️ Technologies Used

* 🌐 HTML
* 🎨 CSS
* ⚙️ JavaScript

## 💻 How to Run

1. 📥 Clone this repository.
